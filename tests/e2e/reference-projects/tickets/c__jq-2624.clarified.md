# gsub loops forever on patterns that can match an empty string

`gsub` with a pattern that can match an empty string, such as `"^"` or `""`, never ends and eventually runs out of memory:

```
$ echo '{"key": "value"}' | jq '.key|=gsub("^";"")'
error: cannot allocate memory
$ echo '{"key": "value"}' | jq '.key|=gsub("";"")'
(hangs)
```

Expected: global substitution finds each match once, moving past an empty match instead of trying the same place again, and always terminates. Matches that are not empty, captures and the flags behave as they do now.

Examples (`filter`, input, output):

```
gsub(""; "a"; "g")         ""       -> "a"
gsub(""; "a"; "g")         "a"      -> "aa"
gsub("^"; ""; "g")         "a"      -> "a"
gsub("^"; "a")             ""       -> "a"
gsub("$"; "a"; "g")        "a"      -> "aa"
gsub("(?=u)"; "u")         "qux"    -> "quux"
gsub("^.*a"; "b")          "aaa"    -> "b"
gsub("^.*?a"; "b")         "aaa"    -> "baa"
gsub("(?<x>.)(?<y>[0-9])"; "\(.x|ascii_downcase)\(.y)")   "A1 B2 CD"  -> "a1 b2 CD"
gsub("\\b(?<x>.)"; "\(.x|ascii_downcase)")                "ABC DEF"   -> "aBC dEF"
[splits("")]               "ab"     -> ["","a","b"]
```
